1 MyPoint.java

Lớp biểu diễn một điểm có tọa độ (x, y) trên mặt phẳng.

Thuộc tính

private int x = 0;
private int y = 0;
  • Mỗi điểm có hai tọa độ nguyên x, y, giá trị ban đầu là 0.
  • private: bên ngoài lớp không truy cập trực tiếp được, phải đi qua getter/setter. Đây là tính đóng gói.

Constructor (hàm khởi tạo)

public MyPoint() {
    x = 0;
    y = 0;
}

public MyPoint(int x, int y) {
    this.x = x;
    this.y = y;
}
  • Không tham số: tạo điểm ở gốc tọa độ (0, 0). Ví dụ new MyPoint().
  • Có tham số: tạo điểm tại tọa độ truyền vào. Ví dụ new MyPoint(0, 4).
  • this.x là thuộc tính của đối tượng, còn x là tham số. Hai cái trùng tên nên phải dùng this để phân biệt.
  • Hai constructor cùng tên nhưng khác danh sách tham số, gọi là nạp chồng (overloading).

Getter / Setter

public int getX() { return x; }            // đọc x
public void setX(int x) { this.x = x; }  // gán x mới
public int getY() { return y; }
public void setY(int y) { this.y = y; }

public int[] getXY() {
    return new int[] {x, y};             // trả về mảng 2 phần tử
}

public void setXY(int x, int y) {      // gán cả 2 tọa độ một lúc
    this.x = x;
    this.y = y;
}
  • getXY() trả về mảng int[]: phần tử [0] là x, phần tử [1] là y.
  • setXY(x, y) thay cho việc gọi lần lượt setX và setY.

Phương thức toString()

@Override
public String toString() {
    return "(" + x + ", " + y + ")";
}
  • Ghi đè (override) phương thức toString() có sẵn của lớp Object.
  • @Override nhờ trình biên dịch kiểm tra: nếu viết sai tên phương thức, nó sẽ báo lỗi.
  • Khi viết System.out.println(p1) hoặc "p1 = " + p1, Java tự động gọi toString() và in ra dạng (3, 4).

Tính khoảng cách: 3 phiên bản nạp chồng

d = √( (x₁ − x₂)² + (y₁ − y₂)² )

p1 đến p2 bằng 3, p1 đến gốc O bằng 5 (tam giác vuông 3-4-5)

// (1) Khoảng cách đến điểm có tọa độ (x, y)
public double distance(int x, int y) {
    int xDiff = this.x - x;
    int yDiff = this.y - y;
    return Math.sqrt(xDiff * xDiff + yDiff * yDiff);
}

// (2) Khoảng cách đến một đối tượng MyPoint khác
public double distance(MyPoint another) {
    int xDiff = this.x - another.x;
    int yDiff = this.y - another.y;
    return Math.sqrt(xDiff * xDiff + yDiff * yDiff);
}

// (3) Khoảng cách đến gốc tọa độ (0, 0)
public double distance() {
    return distance(0, 0);
}
  • xDiff, yDiff là hiệu tọa độ. Math.sqrt(...) lấy căn bậc hai, kết quả kiểu double.
  • Ở (2), another.x truy cập được dù x là private, vì đoạn code này nằm bên trong lớp MyPoint. private giới hạn theo lớp, không giới hạn theo đối tượng.
  • (3) tái sử dụng (1) bằng cách truyền vào (0, 0), không phải viết lại công thức.
  • Java chọn phiên bản nào dựa vào tham số khi gọi: distance(p2) gọi (2), distance(5, 6) gọi (1), distance() gọi (3).

3 TestMyPointArray.java

Tạo một mảng gồm 10 đối tượng MyPoint.

Bước 1: tạo mảng

MyPoint[] points = new MyPoint[10];
null[0]
null[1]
null[2]
null[3]
null[4]
…
null[9]
Lưu ý quan trọng: lệnh này chỉ tạo 10 ô trống, mỗi ô đang là null, chưa có đối tượng nào. Nếu gọi points[0].getX() ngay lúc này, chương trình sẽ báo lỗi NullPointerException.

Bước 2: tạo đối tượng cho từng ô

for (int i = 0; i < points.length; i++) {
    points[i] = new MyPoint(i + 1, i + 1);
}
(1, 1)[0]
(2, 2)[1]
(3, 3)[2]
(4, 4)[3]
(5, 5)[4]
…
(10, 10)[9]
  • points.length bằng 10, nên vòng lặp chạy với i = 0 … 9.
  • Ô thứ i chứa điểm (i+1, i+1). Cộng 1 vì chỉ số mảng bắt đầu từ 0.

Bước 3: in ra

for (int i = 0; i < points.length; i++) {
    System.out.println(points[i]);   // tự gọi toString()
}
(1, 1)
(2, 2)
(3, 3)
...
(10, 10)
